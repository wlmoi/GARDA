# GARDA-chip: agent instructions

Project: **GARDA-chip** (top module `tt_um_garda_chip`), Tiny Tapeout IHP SG13CMOS5L, 8x4 tile (1724.16 x 710.64 um).
Metadata lives in `info.yaml` (title, author, description = "GARDA-chip").

## Show / integrate the GDS
- Final layout: `local_build/gds/tt_um_garda_chip.gds` (KLayout-saved copy: `local_build/klayout_gds/tt_um_garda_chip.klayout.gds`)
- Quick preview image: `local_build/render/tt_um_garda_chip_overview.png`
- Summary as JSON (cells, layers, DB unit, top cell):
  `python tools/gds_view.py info`
- Render PNG (uses KLayout if on PATH, else numpy/matplotlib density overview):
  `python tools/gds_view.py render -o out.png`
- Open interactively: `klayout local_build/gds/tt_um_garda_chip.gds`
- Machine-readable index of all artifacts: `agent_manifest.json`

## Notes
- Top cell: `tt_um_garda_chip`; 280 cells; DB unit 0.001 um.
- Chip art image source: `Calvin.png` (now the Seno pose). The Metal4 art cell in `macros/CALVIN*` was built from the OLD image; regenerate with `tools/chip_art.py` (see `docs/chip_art.md`) inside the LibreLane shell to update the layout.
- `local_build/odb`, `mag`, `mag_gds`, and the old `render/*.png` still use the previous cell name; they are regenerated by `make harden-tt`.
- Do not edit GDS by hand; rebuild via `make harden-tt` (see README.md).
