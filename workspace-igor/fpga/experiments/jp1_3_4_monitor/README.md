# Parallel8 physical UART: JP1 pins 3/4 with JTAG monitoring

This diagnostic project uses **JP1 pin 3 / W12 for UART RX**, **JP1 pin 4 / D11
for UART TX**, and common ground at JP1 pin 12. Adapter TX connects to pin 3;
adapter RX connects to pin 4. Logic level is 3.3 V; adapter VCC is disconnected.
These locations follow Terasic DE10-Nano Figure 3-20. Pins 1/2 are not used by
this image and may remain electrically connected to Jetson, but the original
Jetson inference service on those pins is not implemented by this image.

Open `igor_jp7_monitor.qpf` in Quartus Standard 25.1. The entity/module names
retain the common monitor implementation name; the actual fitted physical
locations are in this directory's `pin_assignment.tcl` and generated `.pin` report.
The neural core and weight banks are copied unchanged from Parallel8.

The JTAG UART commands are `q` (physical RX/decoder/core status), `e` (physical
RX-to-TX echo test), and `i` (normal inference TX; default after reset). Echo is
a wiring/adapter test and does not count as a valid neural inference. The monitor
reports safety stop, transitions, received bytes, framing errors, accepted and
rejected policy requests and core cycles. No STM commands or motor controls are
generated by the diagnostic host script.

Prepare with `python fpga/scripts/prepare_jp7_monitor.py --header JP1_3_4`, then
compile from this directory with `quartus_sh --flow compile igor_jp7_monitor`.
Run the included Icarus testbench before installation. The programming helper
`fpga/scripts/program_uart_monitor.ps1 -Header JP1_3_4` requires a successful
compile, nonnegative timing summary, fitted pad checks, monitor simulation pass
and unchanged neural core hash. It stores a receipt and original programming log.

After programming, close other JTAG/COM12 terminals and run:

```powershell
python fpga/scripts/diagnose_jp7_monitor.py --header JP1_3_4 --port COM12
```

Both the USB-Blaster and COM12 USB–TTL adapter are needed. This records local
runtime evidence and returns to inference mode after the echo tests. Do not
publish raw captures without explicit authorization. Keep KEY1 released and
press/release KEY0 to clear the latched E-stop when appropriate.
