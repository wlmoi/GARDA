# Full Igor inference without SRAM

Active top: `tt_um_wlmoi_igor_neural_logic`, CMOS5L, 8x4 tiles, 50 MHz target. This is the complete 24-64-64-4 Q8.8 network with two signed MAC lanes, hidden ReLU, overflow fault handling, and four clipped outputs. It is not the older safety-gate-only chip.

All 6,020 coefficients are fixed in standard-cell logic; 152 activation words use flip-flops. No physical SRAM is selected by the manifest or physical configuration. The existing upload sequence now verifies each word against the built-in model. A mismatched model is rejected and cannot change coefficients. [Register protocol](../../docs/info.md).

The immutable source is generated by [generate_neural_logic_rom.py](../../scripts/generate_neural_logic_rom.py), which reconciles every layer's weights and biases against the unified export before producing paired reads. `--check` rejects stale constants. [The datapath](../../src/igor_neural_datapath_logic.v) retains its verified 3,080-cycle schedule. The memory access and arithmetic stages remain registered.

The fallback was requested after SRAM integration delayed completion. [Last SRAM attempt](https://github.com/sundaysiagian/peruri-iseedesign/actions/runs/38680155187) passed GDS acceptance and gate-level inference, but failed power-port precheck (56.48 um from bottom versus a 10 um maximum). The active configuration restores the native template step after PDN generation, and requires zero routing/DRC/LVS/power-grid, overlap, setup/hold, slew, and capacitance violations. Precheck, actual routed-netlist inference, and published-layout hash verification must also pass. Archived SRAM reports are not acceptance evidence for this target.

The current RTL passes 100 vectors and 400 independently calculated outputs, all 6,020 parameter readbacks, and overflow and command-ownership guards. The actual IHP post-CTS mapped netlist also passes the submission's two pin-only cocotb tests. These gate-level tests check one complete inference vector, all 6,020 readbacks, nine malformed-host cases, APPEND after COMMIT, `ena` gating and reset recovery. They use functional cell models with zero delay and make no SDF timing claim. At the 50 MHz target, 3,080 compute cycles equal 61.60 microseconds. Host transfer and motor actuation are excluded. Extracted timing acceptance remains pending.

The exact netlist, cell-library, test and model hashes are recorded in [mapped verification](../../evidence/tinytapeout/current/mapped.json). [The evidence index](../../evidence/tinytapeout/current/README.md) links the RTL, generic, mapped and routing reports. Current functional RTL tokens match the archived source of the mapped artifact. Team attribution comments have been corrected to iSeeDesignITB. Initial mapped cell area was about 0.31 mm2. It is not a routed-area or timing guarantee.

The first active logic run (`7ef7ab8`) passed RTL and documentation checks but failed global routing. Restricting signals to Metal2 through Metal4 left Metal3 as the only horizontal signal layer. Metal3 used 97.72 percent of allocated tracks, with 41,837 overflow units overall and 4,797,468 um of wirelength. Standard-cell area after hold repair was 400,217 um2, including 3,022 hold buffers.

The corrected configuration allows signals on Metal1 through Metal4 while keeping clocks on Metal2 through Metal4. Cell obstructions remain active and 10 percent routing capacity remains reserved. A replay of the actual archived post-CTS placement now produces zero global-routing overflow on all four layers. The replay uses the archived 45 percent target density. The current full-flow configuration requests 40 percent. Detailed routing is being completed from the saved global-routing checkpoint. Its status is recorded in [verification.json](../../evidence/tinytapeout/current/verification.json). Global routing alone is not GDS acceptance. Strict congestion, routing DRC, KLayout DRC, LVS, illegal-overlap and timing checks remain enabled.

```sh
python scripts/generate_neural_logic_rom.py --check
python scripts/synth_neural_logic.py

```
